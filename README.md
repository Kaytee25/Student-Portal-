
NUST Student Portal

A small static mockup of the National University of Sciences and Technology (NUST) student portal login page. This repository contains a minimal, responsive login screen intended for UI experimentation and teaching.

Features
- Simple, responsive login form (HTML/CSS)
- Clean, minimal styling for quick mockups

Files
- index.html — the login page
- styles.css — styles for the page

Preview
- Open `index.html` in your browser to view the mockup.

Usage
- Quick (no server): double-click `index.html` or open it from your browser's File ▸ Open menu.
- Serve locally (recommended for testing relative assets):

```bash
python -m http.server 8000
# then open http://localhost:8000
```

Development
- Edit `index.html` and `styles.css` to modify layout and styles.
- Refresh the browser to see changes.
