NUST Student Portal — Login Mockup

This folder contains a small static mockup of the student portal login page.

Files:
- index.html — the login page
- styles.css — styles for the page

To view locally:

1. Open `index.html` in your browser (double-click or use "Open File").

Optional development steps:

- Serve with a static server (Node.js) for local testing:

```bash
# using Python 3
python -m http.server 8000
# then open http://localhost:8000
```
